# Тихо

Контент-студия для самостоятельных массажистов. Из одной идеи или фотографии
создаёт целостную сторис из идеи или нескольких фотографий.

## Принципы первой версии

- без регистрации и внешних трекеров;
- фото отправляются в GigaChat только после явного согласия пользователя и
  удаляются из сервиса после создания концепции;
- тексты избегают диагнозов, обещаний лечения и универсальных медицинских норм;
- результат можно скопировать, а готовую карточку — скачать;
- тема, формат и оформление черновика сохраняются только на устройстве
  пользователя;
- «идея дня» и недельный контент-план помогают публиковаться регулярно.

## Разработка

Требуется Node.js 22.13 или новее.

```bash
pnpm install
pnpm exec vinext dev
pnpm exec vinext build
node --test tests/rendered-html.test.mjs
```

## ИИ через GigaChat

В продакшене сайт обращается к GigaChat через функцию `backend/` в Yandex
Cloud. Такой шлюз нужен из-за цепочки российских TLS-сертификатов: браузер
пользователя не связывается с GigaChat напрямую, а ключ остаётся только в
переменных окружения серверов.

Переменные сайта:

- `GIGACHAT_CREDENTIALS` — ключ авторизации GigaChat;
- `GIGACHAT_SCOPE` — обычно `GIGACHAT_API_PERS`;
- `GIGACHAT_RELAY_URL` — публичный URL функции Yandex Cloud.

Функция принимает запросы только с правильным `X-Relay-Key`, ограничивает
размер входных данных и не возвращает внутренние ошибки или секреты клиенту.
